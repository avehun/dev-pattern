# План: переделка dev-pattern в плагин

Статус: готово, ждёт ревью · ветка `plugin-redesign` · начат 2026-10-12

## Цель

Репозиторий становится маркетплейсом с одним плагином `dev-pattern`:
база знаний, которую ведут Sonnet-исследователи; обязательный план перед любой работой;
блокирующая проверка обновления документации; два режима учителя. Установка в чужой
репозиторий ничего не ломает.

## Принятые решения

- Основная сессия — Opus: решает и пишет код. Механические правки может отдать
  Sonnet-`worker`, объявив это в плане (критерии: задача определена, контекст узкий,
  много шагов или объёма).
- Исследование — Sonnet-`researcher`; он сам пишет черновики модулей базы знаний.
- План всегда; в чате, в файл (`docs/dp/plans/`) — только если работа многосессионная.
- Данные в проекте — `docs/dp/` (knowledge/, plans/).
- Stop-хук блокирует, если код изменился, а документация нет; выход — `dp-docs-waive "причина"`.
- Старый пайплайн (spec/cards/review) удаляется полностью.
- Установка: плагин + `/dev-pattern:setup` в режиме «общий» или «только для меня».
